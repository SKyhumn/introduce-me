Introduce Me - 자기소개 및 포트폴리오 정리 웹앱

기간 : 2025.03.11~2025.03.11 / 개인프로젝트


새로운 프로젝트, 기술 학습 시 포트폴리오 웹을 주기적으로 업데이트하여 기록하고 있습니다.


주요 기능 :

  • - 섹션별로 자기소개와 포트폴리오를 정리하여 가독성 향상
  • - Typed.js 라이브러리를 활용해 타이핑 애니메이션 적용
  • - scrollIntoView를 활용한 페이지 이동 구현
  • - 문의/연락 폼 구현

스택 :

  • - Frontend
    • - HTML5 : 화면 구조 구현
    • - CSS3 : 화면 스타일링
    • - JavaScript : 타이핑 애니메이션 및 섹션 이동 구현
  • - Other Tools
    • - GitHub : 버전 관리
    • - netlify : 프로젝트 배포 및 실시간 URL 제공

배운 점 :

  • - HTML, CSS, JS를 이용하여 웹 개발 기초 역량 강화
  • - 구조화 된 레이아웃과 스타일링 구상 능력 향상
  • - JS에서 Typed.js 라이브러리로 타이핑 애니메이션 구현으로 UI 표현력 강화
  • - scrollIntoView를 통한 페이지 이동 구현으로 UX 개선 경험

마이노트 - 노트 작성 / 수정 / 삭제 및 카테고리 분류를 통한 노트 관리 웹앱

기간 : 2026.03.05~2025.03.17 / 개인 프로젝트


React와 Firebase를 활용하여 인증, 실시간 데이터 처리, 상태 관리를 포함한 풀스택 흐름을 직접 구현한 노트 웹 애플리케이션입니다.


주요 기능 :

  • - Firebase Authentication 기반 로그인 / 회원가입 등 인증 시스템 구현
  • - 노트 CRUD(작성, 조회, 수정, 삭제) 기능 구현
  • - 노트 검색 기능 구현
  • - 카테고리 분류를 통한 체계적인 노트 관리
  • - onAuthStateChanged을 활용한 사용자 인증 상태 확인
  • - Firestore의 onSnapshot을 활용한 실시간 데이터 동기화

      • • 로그인 & 회원가입 인증 기능 구현

      • • 노트 및 카테고리 CRUD(생성, 조회, 수정, 삭제) 기능 구현
      • • 카테고리별 노트 분류 기능 구현
      • • 검색 기능을 통한 노트 필터링
    • - Tailwind css

    • - TypeScript
      • • 상태, props 응답 타입 정의
      • • 명확한 타입 지정으로 코드 안정성 및 버그 최소화, 유지 보수성과 가독성 향상
