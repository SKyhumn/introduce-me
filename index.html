Introduce Me - 자기소개 및 포트폴리오 정리 웹앱

기간 : 2025.03.11~2025.03.11 / 개인프로젝트


새로운 프로젝트, 기술 학습 시 포트폴리오 웹을 주기적으로 업데이트하여 기록하고 있습니다.


주요 기능 :

  • - 자기소개 및 포트폴리오 정리
    • - 사용자가 쉽게 내용을 확인할 수 있도록 섹션별로 정리
  • - 네비게이션 버튼 클릭 시 스크롤 이동
    • - 각 메뉴 클릭시 해당 섹션으로 부드럽게 이동
    • - JS에서 scrollIntoView 활용을 통해 섹션 이동 구현
  • - 폼 UI 구현
    • - 간단한 문의/연락 폼 제작

스택 :

  • - Frontend
    • - HTML : 화면 구조 구현
    • - CSS : 화면 스타일링
    • - JavaScript : 타이핑 애니메이션 및 섹션 이동 구현
  • - Tools
    • - GitHub : 버전 관리
    • - netlify : 프로젝트 배포 및 실시간 URL 제공

배운 점 :

  • - HTML, CSS, JS를 이용하여 웹 개발 기초 다지기
  • - 구조화 된 레이아웃과 스타일링 경험 습득
  • - JS에서 Typed.js 라이브러리로 타이핑 애니메이션 구현으로 UI 표현력 강화

봉봉쇼랭킹 - 로봇 가위바위보 유저 결과 랭킹 웹앱

기간 : 2025.12.11~2025.12.24 / 팀 프로젝트


하드웨어 전공 팀원이 제작한 가위바위보 로봇과 대결하여 승수의 오름차순대로 유저들의 랭킹을 알 수 있습니다.


주요 기능 :

  • - 로그인 및 회원 가입 기능
    • - 로그인 회원가입 기능 구현을 통해 사용자 인증 흐름 이해
    • - 리액트 상태 관리와 Axios.post를 통해 사용자 정보를 서버에 안전하게 전송, 이메일 인증 기능 구현
    • - 이메일 및 비밀번호 규칙 지정으로 보안 강화 및 사용자 유효성 처리
    • - 에러 및 처리 실패 시 조건부 렌더링으로 사용자에게 명확한 오류 메세지 제공
  • - 비밀번호 재설정 기능
    • - 리액트 상태 관리와 Axios.post를 통해 이메일 인증 및 비밀번호 재설정 구현
    • - 이메일 및 비밀번호 규칙 지정으로 보안 강화 및 사용자 유효성 처리
    • - 에러 및 처리 실패 시 조건부 렌더링으로 사용자에게 명확한 오류 메세지 제공
  • - 내 정보 확인
    • - 로그인 후 Axios.get을 통해 JWT를 포함한 API 요청으로 사용자 프로필 조회
    • - file태그 + Axios.post를 통해 사용자 프로필 사진 변경
    • - 전적(승/패/무) 렌더링
    • - Polling을 활용하여 일정한 주기마다 사용자 프로필 업데이트
  • - QR인증으로 로봇과 게임 시작
    • - react-qr-reader 라이브러리 사용
    • - 백엔드 전공 팀원이 파이썬 코드를 실행하여 QR창이 나오면 인증
    • - Axios.post를 통해 QR인증 후 인증 성공 메세지 전달
    • - QR이 인증되면 로봇이 사용자 데이터를 생성(사용자 전적 및 순위에 영향을 줌)
  • - 랭킹 확인
    • - Axios를 이용한 조건부 렌더링으로 로그인 시 랭킹 조회
    • - Polling을 활용하여 일정한 주기마다 실시간 랭킹을 화면에 업데이트
    • - 상태 관리와 filter를 사용하여 상위 10위 랭킹 조회
    • - "랭킹 전체 보기" 버튼으로 Axios.get을 이용해 유저 전체 랭킹 조회
  • - 로그아웃 및 회원 탈퇴
    • - Axios.post를 통해 로그아웃 기능 구현
    • - 로그아웃 성공 시 로그인 페이지 렌더링
    • - Axios.delete를 통해 회원 탈퇴 기능 구현
    • - 회원 탈퇴 성공 시 로그인 페이지 렌더링
    • - 회원 탈퇴 후 재로그인 불가능
